About Cryptography

Caesar Cipher

A substitution cipher where each alphabetic character is shifted by a fixed amount. Example: with key 3, A becomes D.

Vigenère Cipher

A polyalphabetic substitution cipher. The letters of a keyword determine different shifts for successive plaintext letters.

SHA-256

SHA-256 is a cryptographic hash function that produces a 256-bit digest, normally represented as 64 hexadecimal characters. Hashing is one-way and is not decryption.

Brute Force

For a Caesar cipher, only 25 non-trivial shifts exist, so an attacker can try every shift and inspect the results.
